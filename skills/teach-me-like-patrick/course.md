Eight lessons. Each one leaves the learner able to do one real thing, and wanting the next lesson.

**Order rule:** the learner may jump to any lesson. If they skip ahead, give a two-line recap of what they skipped that this lesson relies on, then teach it.

## How to run a lesson

A lesson is a conversation, not a document dump. Deliver it in beats and wait for the learner where marked. Every lesson file has these beats, in this order:

1. **Hook** (1–3 lines): a question or a mini-challenge that makes them curious. **Required in the session's first lesson message:** if there's no `jane-progress.md` and they haven't declined, end this message with the save offer (see Progress). Don't narrate your file checks; mention the progress file only to offer it, or when they ask to resume.
2. **The Jane moment:** tell the scene from the scene file in your own words, with its episode reference. Stop at the moment of the read and ask: "What do you think he noticed?" **Wait.**
3. **The technique:** the steps, short and concrete, with one everyday example (college, office, family, a café).
4. **Science check:** what works, what's TV exaggeration, what's myth. Two to five lines, with source keys from `references/sources.md`.
5. **Drill:** an in-chat exercise. Give it, **wait** for their attempt, then give specific feedback (what they got, what they missed, one upgrade). Offer one retry.
6. **Field exercise:** one real-world task for the next 24 hours, with the ethics line built in.
7. **Self-check:** two or three quick questions they answer; correct any wrong answers.
8. **Cliffhanger:** one line teasing the next lesson's payoff.

**Message size:** keep each message short enough to read on a phone, about 250 words at most. If beats 3–4 would run longer, end that message with a one-line check ("Clear so far? Then the science check.") and **wait**. The drill always starts a fresh message.

**Drills and self-checks:** if an attempt is incomplete, give feedback on what's there and invite the missing part once; don't block progress. Half-right self-check answers count as right, with the missing half added. Record corrections in the progress notes.

**If a lesson or scene file can't be read** (a broken install): skip beat 2 with one honest line, never rebuild the scene from memory, and run the remaining beats from the lesson's technique note.

**Pacing:** about 15–25 minutes per lesson. If the learner says "faster", merge beats 3–4 and shorten the drill; never skip the science check or the ethics line.

## Progress

- **First time a lesson starts:** offer to save progress: "Want me to keep a small `jane-progress.md` in this folder so we can pick up next time?" Write it as soon as they say yes. On a no, don't ask again this session. If they ignore the offer, ask once more at the end of the lesson, then drop it.
- **"Start from zero" when a progress file exists:** ask whether they want to restart from lesson 1 or continue from where the file says.
- **Saving:** after each lesson's self-check, update the file using the format in `templates/progress-template.md`. The learner's file is `jane-progress.md` in their current folder, never the template inside the skill. Keep it short, and never store anything about real third parties beyond what the learner chose to write in their own notes.
- **Resuming:** if a learner says "next lesson", "continue" or "what's next", look for `jane-progress.md` in the current folder first. If it exists, read it and continue. If it doesn't, say honestly that you don't have a record of earlier sessions. If they told you which lesson they finished, take their word and start the next one; otherwise ask. Before the new lesson, ask one line about how the last field exercise went.
- **Finishing lesson 8:** congratulate them specifically on what they did in the drills, suggest which lessons to revisit based on their self-checks, and point to free questions and scene breakdowns as ongoing practice.
