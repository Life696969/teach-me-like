# Sources

Every citation below was checked against its DOI record or publisher page on 2026-10-24. "Supports" is written in our own words. Where a figure came only from secondary summaries, it says so. The skill quotes none of these works; it paraphrases and cites.

**How to use this file (for the agent):** when a learner asks "is that real?" or "source?", give the citation and the one-line "supports". Never invent a source, a number or a finding that isn't here.
