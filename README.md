# Teach Me Like

Free Agent Skills that teach real skills through the characters who made them famous, with an honest science check on every trick.

## Teach Me Like Patrick

Learn to read people the way Patrick Jane does in *The Mentalist*: observation, cold reading, baselines, catching lies, rapport, influence and misdirection, and the memory palace. Every technique comes with what actually works, what's TV exaggeration and what's a myth, backed by real research.

**Three ways to use it:**

- **The course:** 8 lessons, one at a time, each with a real Jane moment, a drill, a field exercise and a self-check. It can save your progress in a small `jane-progress.md` (only if you say yes) so you can pick up later.
- **Free questions:** "How do I know if someone's nervous or lying?", "How do fake psychics do it?"
- **Scene breakdowns:** decode six verified scenes, from the Pilot's kitchen read to the twenty-heads coin trick.

It talks in your language: English, Hinglish, whatever you write in.

## Install

The skill is the folder `skills/teach-me-like-patrick`. It follows the open [Agent Skills](https://agentskills.io) format, so it works in many coding agents.

**Claude Code**
- For one project: copy `skills/teach-me-like-patrick` into `.claude/skills/` inside your project folder.
- For every project: copy it into `~/.claude/skills/`.

Then just say: *"teach me like patrick jane, start from zero"*.

**Codex, Gemini CLI, Cursor, GitHub Copilot and other agents that support Agent Skills**
- Copy the folder into the skills directory your agent reads. Many read `.agents/skills/` in your project or `~/.agents/skills/` for all projects; check your agent's docs.

**With the skills CLI**
```bash
npx skills add Life696969/teach-me-like
```

**Claude.ai (no coding agent needed)**
- Download `teach-me-like-patrick.zip` from the [Releases page](https://github.com/Life696969/teach-me-like/releases) and upload it as a custom skill in Claude.ai's settings (custom skills need a plan and settings that allow them). Then start a chat and say *"teach me like patrick"*.

## Honest by design

- **No made-up scenes.** The coach only breaks down six scenes that were checked against multiple sources, and retells them in its own words. Ask about any other scene and it will tell you it doesn't have it verified rather than guess.
- **Real science, cited.** Every claim comes from a checked source list (`skills/teach-me-like-patrick/references/sources.md`), and the skill tells you when TV and research disagree. For example: no body-language "tell" proves a lie.
- **A coach, not a character.** It teaches Jane's methods; it doesn't pretend to be him.
- **Ethics built in.** It teaches how influence works and how to spot it used on you. It won't help you manipulate, hypnotise or "test" a specific real person, and it shows you the honest version instead.
