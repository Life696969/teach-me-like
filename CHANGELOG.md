# Changelog

## teach-me-like-patrick 1.0.0 (2026-10-25)

First release.

- Three modes: an 8-lesson course, free questions and scene breakdowns.
- Six scenes checked against multiple sources, retold in our own words.
- Six technique notes with a science check on each (works / TV exaggeration / myth).
- A verified source list (56 citations, with DOIs where available).
- Optional progress saving in `jane-progress.md` (format v1), written only with the learner's OK.
- Replies in the learner's language, Hinglish included.
- Tested in real Claude Code sessions: no invented scenes, no "tells" checklists, no help manipulating a specific person, and saving then resuming across sessions.
